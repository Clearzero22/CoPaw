## 🎯 核心功能

### 1. 多渠道支持
- **国内平台**：钉钉、飞书、企业微信、QQ、小易
- **国际平台**：Discord、Telegram、Matrix、Mattermost、iMessage
- **特殊渠道**：MQTT、Voice、Console

### 2. AI Agent 能力
- 基于 ReAct 框架的智能代理
- 46+ 内置工具（文件、Shell、搜索、浏览器等）
- 自动记忆压缩和管理
- 多模态输入输出

### 3. 技能系统
- 16+ 内置技能（Cron、新闻、文档处理等）
- 自定义技能开发
- 热加载和卸载

### 4. 模型支持
- 云模型：OpenAI、Anthropic、Gemini、DashScope
- 本地模型：llama.cpp、MLX、Ollama
- 多模型路由和协作
