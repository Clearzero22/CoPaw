## 🎯 集成模式速查

### 模式 1: 三层代理模式
```
前端 → CoPaw 后端 → 外部服务
```
**适用**: API 服务集成

### 模式 2: 插件化模式
```
CoPaw 核心 → 插件管理器 → 功能插件
```
**适用**: 可复用功能模块

### 模式 3: 事件驱动模式
```
用户操作 → 事件总线 → 订阅者处理
```
**适用**: 异步任务和实时通知

### 模式 4: 数据库集成模式
```
外部服务 → 数据同步 → 本地数据库
```
**适用**: 需要持久化的数据
